# Multilingual Knowledge Assistant

A Python-based RAG application for asking questions
about PDF documents in English, French, and Arabic.

## Features
- PDF ingestion and text extraction
- Semantic search with embeddings and FAISS
- Local LLM inference through Ollama
- Answers with page-level citations
- FastAPI backend and Streamlit frontend
- Automated tests and evaluation tools
